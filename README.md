## 📌 项目简介

在小屏幕智能穿戴设备上，我们时常需要随手记录关键灵感、临时待办备忘或重要信息。然而，**市面上绝大多数智能手环由于屏幕狭小、算力受限，普遍缺失可用的原生输入法**，用户只能从手机端单向同步文本，无法在手环本地直接创建和编辑便签。

`BandNotepad`（腕上记事本）专为 **小米手环 9 Pro**（336×480 分辨率）深度定制研发。内置轻量级 T9 拼音输入引擎与 3500 常用字频字典，支持全屏大字候选展开、下划线光标自由定位、切片式插入与删除，无需任何手机端伴侣应用，即可直接在手环上享受独立、完整的便签记录体验！

## ✨ 核心特性

- ⌨️ **多模态全功能腕上输入法 (IME)**：
  - **T9 九键拼音**：基于国家标准 3500 常用汉字词频排序，输入数字序列即时匹配合法拼音，支持**预选拼音音节过滤**（如输入 `78` 快捷预选 `qu`、`226` 预选 `can/ban/cao`），大幅缩减翻页耗时。
  - **全屏候选字大网格**：独创 4×4 大字展开面板，25px 超大字号杜绝误触，支持上下页翻页检索全部候选字。
  - **英文九键 & 26 键 QWERTY**：提供大触控区的英文 T9 盲打与标准 26 键全键盘，支持 Shift 大小写切换。
  - **常用标点符号面板**：精选 30+ 种高频中英文标点、算术符号与数字网格快速点选。
- 📍 **精准光标定位与中间文本编辑**：
  - **下划线样式光标 (`_`)**：直观指示当前文本插入点，顶部状态栏实时显示 `光标位置/总字数` 精准数字反馈。
  - **浏览模式专属控制栏**：收起键盘时底部常驻轻量工具栏：`|‹`（行首）、`‹`（左移）、`›`（右移）、`›|`（行尾）、`⌫`（直接删除）、`⌨ 打字`（光标处呼出插入）。
  - **键盘联动微调**：九键模式下未输入拼音时，底部 `‹` 与 `›` 自动转为光标移动键，无需收起键盘即可微调插入点。
- 📳 **物理触觉震动反馈**：每次敲击按键均调用手环线性马达短震反馈 (`@system.vibrator`)，赋予小屏幕敲击机械确认感。
- 💾 **即时防丢持久化**：基于 `@system.storage` 实现无感即时存盘与生命周期容灾（`onHide` / `onDestroy` 自动持久化），完全规避手环息屏与内存清理导致的数据丢失。
- 🔋 **AMOLED 纯黑能效与超轻包体**：336×480 像素点对点精准渲染，深色模式零额外功耗，无外部原生依赖，打包产物（RPK）仅约 **36KB**，启动零卡顿，无 OOM 风险。

## 🚀 快速开始

### 方式一：直接安装预编译 RPK（最推荐，无需配置开发环境）

1. 从本项目仓库的 `dist/` 目录获取预编译包：
   - `dist/com.xiaomi.band.notepad.debug.1.6.0.rpk`
2. 打开手机端或电脑端的侧载工具（如 **AstroBox** 或 **表盘自定义工具**）。
3. 确保手环已通过蓝牙正常连接。
4. 选择上述 `.rpk` 文件推送到手环，等待传输完成后即可在应用列表直接启动。

### 方式二：从源码构建

1. **准备环境**：
   确保本地已安装 Node.js (推荐 v18+)，并全局安装小米 Vela 快应用构建工具：
   ```bash
   npm install -g aiot-toolkit
   ```
2. **克隆仓库与安装依赖**：
   ```bash
   git clone https://github.com/KaiTeeDreamChai/band-notepad.git
   cd band-notepad
   npm install
   ```
3. **编译构建**：
   ```bash
   # 编译 Debug 安装包
   npm run build

   # 编译 Release 正式包
   npm run release
   ```
   构建生成的 `.rpk` 文件将存放于 `dist/` 目录中。

> **系统要求**：支持运行快应用的小米手环 9 Pro（Xiaomi Vela OS / HyperOS）。

## 💡 使用指南

1. **新建与管理便签**：
   - 首页点击 `＋ 新建便签`，即可进入编辑页面并自动呼出输入法。
   - 列表中点击任意便签卡片即可打开浏览；点击卡片右侧的 `删` 按钮可删除该条便签。
2. **打字与拼音输入**：
   - 在拼音九键模式下输入数字（如 `226`），候选栏上方将出现预选拼音（如 `can`、`ban`、`cao`）。
   - 点击指定拼音音节可精准过滤候选字；直接点击 `⤢` 可展开 4×4 全屏大字面板快速挑选。
   - 点击中英文切换栏可在 `拼音9`、`英文9`、`英文26` 与 `符号` 模式间切换。
3. **浏览与光标编辑**：
   - 单击文本显示区即可收起/唤起虚拟键盘。
   - 键盘收起后，底部显示光标控制栏：使用 `‹` / `›` 移动光标，`|‹` / `›|` 跳至首尾，点击 `⌫` 可直接删除光标前文字，点击 `⌨ 打字` 可在当前位置立即插入新内容。

*(输入操作速查表)*：

| 按键 / 操作 | 功能说明 |
| :--- | :--- |
| **单击文本区域** | 切换呼出 / 收起虚拟键盘 |
| **拼音状态按 ‹ / ›** | 切换选定拼音音节或翻页候选字 |
| **空码状态按 ‹ / ›** | 在文本中间左移 / 右移输入光标 |
| **长空格键** | 优先上屏当前首个候选汉字，无候选时输入空格 |
| **⤢ 展开按钮** | 进入 4×4 全屏大字候选网格，支持跨页翻阅 |
| **‹ 存盘返回** | 自动存盘并返回便签列表 |

## ⚠️ 注意事项与说明

- **手环内存保护机制**：Vela OS 对穿戴式快应用有严格的 RAM 限制。本项目字库经过高强度哈希索引与体积压缩（整体体积仅 30+KB），严格避免内存超限或进程崩溃。
- **后台与息屏特性**：手环系统在息屏或退回表盘时可能随时挂起或销毁应用。本项目在每一个文字修改点以及 `onHide` / `onDestroy` 钩子均触发了即时落盘，无需担心丢内容。
- **设备适配**：本程序针对 336×480 分辨率与微曲面安全边距调优。若在其他分辨率的手环上运行，请在 `src/manifest.json` 中调整 `designWidth`。
